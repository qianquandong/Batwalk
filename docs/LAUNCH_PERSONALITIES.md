# 首发 20 只 · 通用与专属动作实现

按 [`BAT_ACTIONS.md`](BAT_ACTIONS.md) 原有设计实现 **64 / 64** 个首发动作。
18 只各 3 个；星系蝠、日蚀蝠各 5 个。没有增加惩罚、消耗、定位采集或存档字段。
本改动用于测试，不触发 TestFlight、上架、自动合并或签名发布。

五个通用动作也已补齐：**100 段 / 400 帧**，含保留的麻薯 5 段 / 20 帧，
新增其余 19 只的 95 段 / 380 帧。合计首发 **164 段 / 656 帧**。
Watch 和 iPhone 通过同一目录与播放规则使用这些素材。

## 播放规则

- Lv.1：两只传说的孵化登场。Lv.2：日常习惯。Lv.3：专属互动反应。
  Lv.4：招牌动作。Lv.5：传说隐藏动作。
- 被摸、喂食、散步归来、新一天按 `ActionCatalog` 的原始 trigger 选动作。
  未解锁时保留通用动作；一次互动和升级命中同一个动作时只播放一次。
- 升级跨过多个等级时逐个庆祝新解锁；动画本身不会加经验或扣果子。
- 白天 / 黄昏 / 夜晚按 `BatMood.resting` 对应时段选择习惯。
  出现后先等约 8 秒，后续间隔至少 16 秒；每个动作在当前角色视图存续期间、
  同一当地日期和时段只自然播放一次。日期切换清空这段表现记忆。
- 传说隐藏动作：Lv.5，每分钟最多一次 1/24 随机机会，每个角色视图存续期间每天最多一次。
  星系只在夜晚，日蚀只在白天。重新进入全新的角色视图会重新开始表现记忆；
  这不是跨设备的动作发现记录。
- 暂停、退后台、切走页面、Always-On 降亮度、Reduce Motion 时停止逐帧播放。
  一次性请求先消费再播放，抬腕不重播旧请求。底层画面在动作回看弹窗打开时暂停。
- Watch 陪伴页与 iPhone 图鉴提供 3 个普通专属动作的回看弹窗，遵守友谊等级。
  登场和稀有动作不在普通回看列表中提前剧透。

## 素材与预览

[本地交互画廊](../Art/gentle-pixel/launch-actions/index.html) 可切换 164 个动作、暂停和逐帧看，
同时展示 Watch / iPhone 尺寸。App 的 Debug Settings → Animation samples 可以切换
全部角色、Lv.1–5 和任意已解锁动作，不改变真实存档。

素材总计 **256 帧：64 段，每段 4 帧**。以用户确认的 `portraits-v3` 为唯一角色原型，
使用 imagegen 延展姿态。长耳「偷听瓢虫」、果果「抱紧水果」、月翼「躲月亮」保留已确认样板；
麻薯沿用已有的三个匹配动作。原立绘文件不修改，源图哈希、生成提示词、裁切坐标及帧锚点均保留。
每段采用一个统一缩放比例，保留各帧的相对大小与位移，不通过拉伸制造角色差异。
运行 `python3 Art/tools/package_portrait_actions.py` 同步 PNG、清单及 Swift 时长；`--check` 只校验。

首发五个通用动作从 Lv.1 即可用：待机眨眼、闭眼睡觉、原有翅膀飞行、被摸时放松、吃果子。
动作依照每只原立绘展开；洞穴保留斗篷，只轻摆翅尖悬停，月翼轻开月牙翼，水晶活动晶体翼。
麻薯沿用原试制动画，其余 19 只使用 `universal_bat_`。待机一轮约 3 秒后休息 4 秒，
睡觉一轮约 2.8 秒后休息 3.6 秒；互动约 0.8–2 秒，遵守原有暂停及无障碍规则。
打包命令为 `python3 Art/tools/package_portrait_universals.py`，加 `--check` 可只校验。
原图、精确提示词、五份飞行修正及裁切清单见 [通用动作来源](../Art/gentle-pixel/portrait-universals-v1/README.md)。
Wave-two 保留 Sticky / Walker 动画，其余 10 只仍使用原立绘。
原有 `gen_bat_` 探索素材不再被播放器选择；未解锁的专属动作不会用作通用替代。

星系「迁徙轨迹」使用象征性的星点路线，**不读取 GPS 或真实步行轨迹**。
日蚀的遮光效果限制在角色画布内，不强行调节系统亮度或整页闪屏。
Shiny 沿用现有统一色相旋转；专门的 Shiny 配色不在本次范围。

## 验证

- Core tests：等级、触发器、跨级解锁、去重、时段、稀有频率、取消消费。
- Art tests：100 段通用 / 400 帧和 64 段专属 / 256 帧、资源哈希与尺寸、透明边界、原立绘哈希、样板原图与锚点、麻薯原有逻辑像素、每段多种姿态。
- App hosted tests：逐一加载全部 656 个首发资源，防止漏打包，并检查 wave-two 静态回退使用原立绘。
- GitHub CI：上述检查、Watch 和 iPhone 无签名模拟器编译、iPhone 宿主测试、可选 capability 编译。
- 已检查全部动作帧表和交互画廊；真实手表的观感、耗电及触感仍需设备验证。

12 只 wave-two 暂不新增专属动作；其中 Sticky / Walker 的原有招牌仍保留。
