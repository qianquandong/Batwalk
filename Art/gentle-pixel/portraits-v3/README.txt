Batwalk · 32 个小性格 · 原始立绘探索 v3

这版把 C Gentle pixel 作为统一的绘画语言。每个角色另行设计主题、面孔、身体构成、静态姿态和性格。
角色名单与稳定 ID 对齐 PR #2 的 32 只蝙蝠；独特动作见 manifest.json 的 actionReferences。

文件：
  roster.png：带名字和角色设定的 32 只全阵容。
  preview.png：六只代表角色预览。
  portraits/：32 张独立透明底原始 PNG，保留生成文件的全部像素及透明度。
  review-small-size.png、review-64px/：64px 小尺寸检查，仅作评审预览。
  prompts.json：每只的完整生成提示词；使用内置 image_gen。
  manifest.json：编号、稳定 ID、设定、文件、来源动作和文件校验值。
  verification.json：数量、尺寸与透明通道检查。

当前是原始角色立绘，用来评审形象、气质和整套阵容的差异。正式动画前仍需统一逻辑像素网格、调色板、拆件和动作帧。
大黄蜂蝠、吸盘蝠、棉花糖蝠使用用户所附 C 面板作为画法参考；其余角色按各自独立设定生成。
拟人化造型、道具与性格属于艺术创作，真实蝙蝠的行为仅作为灵感。原有动作数据与游戏代码未在这一批立绘工作中修改。
