# Generated animation sets (`gen_bat_…`)

Every species that is not one of the three hand-drawn pilots (Mochi, Sticky,
Walker) animates with frames generated by the Gentle-pixel engine in
[`Art/tools/gentle_pixel/engine.js`](../../tools/gentle_pixel/engine.js): one
part library (bodies, ears, wings, faces, motifs) with each species' own
proportions, palette and props, drawn on the 64 px logical canvas, outlined and
rim-shaded once. Review sheets for all 32 species are in this folder (one row
per action, frames left to right); `manifest.json` lists every asset name and
the frame plan.

| Action | Frames | Seconds per frame | Rest on frame 0 |
|---|---|---|---|
| idle | 8 | 0.6 · 0.14 × 6 · 0.2 | 1.6 s |
| sleep | 8 | 0.32 × 8 | 0.8 s |
| fly | 6 | 0.1 × 6 | — |
| pet | 8 | 0.12 × 8 | — |
| eat | 8 | 0.18 · 0.14 · 0.14 · 0.22 · 0.2 · 0.2 · 0.22 · 0.3 | — |

The plan is `PLAN` in `engine.js` and `GeneratedFramePlan` in
`Packages/BatwalkCore/Sources/BatwalkCore/BatAnimation.swift`; the core tests
check that the catalog's clips match it. Change both together, then re-export.

## Regenerate

```bash
node Art/tools/gentle_pixel/export_frames.js            # all 32 species, 1,216 frames
node Art/tools/gentle_pixel/export_frames.js cocoa fox  # just these
```

Writes `Apps/Shared/Sprites.xcassets/gen_bat_<id>_<action>_<n>.imageset/`
(128 × 128 PNG at 2×, nearest-neighbour — the same contract as the pilots) and
refreshes the sheets here. Node only; no packages.

## Who uses what

- `PilotAnimationCatalog.pilotSpeciesIDs` → `pilot_bat_…` (4 frames + a signature).
- `PilotAnimationCatalog.generatedSpeciesIDs` → `gen_bat_…` (6–8 frames, no
  signature yet, so the player never waits on missing art).
- `SpriteResolver` prefers a species' first idle/sleep frame, so tiles, cards and
  the Watch hero all show the same art for a species.
- Mochi, Sticky and Walker keep their approved pilot frames. To use the generated
  look for them too, move the ids from `pilotSpeciesIDs` to the generated list
  and re-export (the frames already exist in the catalog).

Shiny still uses the player's hue rotation; the engine's designed Shiny
colourways (Mochi, Cocoa, Long Ear) are on the design canvas and can be
exported as `_shiny` frames when the player learns to pick them.
